# Twitter Clone

A responsive, front-end recreation of the X (formerly Twitter) home page, built with HTML, Tailwind CSS, and Vite.

## Features

- Responsive sidebar, timeline, and discovery panel
- Home feed with sample posts and profile content
- Tailwind CSS styling

## Getting started

### Requirements

- Node.js and npm

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Vite prints the local development URL in the terminal.

### Build for deployment

```bash
npm run build
```

The build generates Tailwind CSS and outputs the deployable site to `dist/`.
